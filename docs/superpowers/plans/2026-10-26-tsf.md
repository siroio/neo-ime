# TSF and IME control implementation plan

> Execute inline with superpowers:executing-plans. User approved proceeding;
> repository instructions prohibit unsolicited commits/worktrees.

**Goal:** TSF input, reconversion, open/close and conversion-mode control with
readable native C++.

**Architecture:** Add an owning-GUI-thread TSF backend beside IMM32. Share the
existing Lisp rendering, preserving buffer identity, ordered edits and Undo.

**Tech Stack:** C++20, Win32/COM/TSF, Emacs Lisp, MinGW, ERT.

**Spec:** ../specs/2026-10-26-tsf-design.md

## Global constraints

- Only neo-ime; no installed copies, commits, pushes, or worktrees.
- C++20 / Google clang-format; use platform constants and named protocol fields.
- No Emacs API calls from GUI thread; no circular cross-thread waits.
- Preserve IMM32 fallback and existing UI/Undo behavior.

## Review focus

- Partial commits between polls must survive; test multiple queued edits.
- Buffer changes/reconversion cancellation must preserve original text.
- Focus/window destruction must not leave callbacks using released COM objects.
- UTF-16 surrogate boundaries and invalid ranges must reject unsafe edits.
- Read-only buffers, unknown state, and failed setters must not report success.
